# Future Roadmap

This document outlines the planned features and improvements for Forguild.

## Phase 1: MVP Enhancements
- [ ] Implement user authentication (login/registration).
- [ ] Basic event creation and listing.
- [ ] Connect React frontend with Django REST API.

## Phase 2: Advanced Features
- [ ] User profiles and dashboards.
- [ ] Event RSVP and ticketing system.
- [ ] Email notifications and reminders.

## Phase 3: Scaling & Deployment
- [ ] Containerize applications using Docker.
- [ ] Setup CI/CD pipelines.
- [ ] Deploy to production environment (e.g., AWS, Heroku).
